## 1. Definition

A MULTI_AGENT_RELAY_CHAIN is an evidence topology in which knowledge
material circulates between multiple AI systems with the founder acting as
the router and decision layer:

```
AI/agent artifact
    -> Derek control/adoption act (e.g. "What if I added in this.",
                                    "yes let's do the above:")
    -> another AI/agent (relayed, labeled or unlabeled)
    -> refinement
    -> Derek integration act (save, build, bring into operations)
    -> operating system / workspace artifact (Notion, repos, specs)
```

This is NOT Derek authorship of the relayed text. It CAN be strong
evidence of Derek-directed integration and operationalization.

## 2. Axis separation (founder directive, 2026-08-12)

The pattern describes topology only. All existing axes stay separate and
are never collapsed:

| Axis | Values |
|---|---|
| Authorship | assistant / external / unknown (D0 only via provenance proof) |
| Submission | Derek |
| Adoption | AD0-AD4 |
| Integration | measured separately (see section 4) |
| Relay actors | e.g. WorkClaw -> Genspark -> Hermes Relay -> Derek -> ... |

Target proposition shape this enables:

> Assistant-originated / AD4 founder adoption / high operational
> integration

— never mislabeled as Derek-originated.

## 7. Event taxonomy (founder addition, 2026-08-12)

Relay is NOT one generic edge. Distinct event classes, never collapsed:

```
ORIGIN      -> RELAY -> TRANSFORM -> ADOPT -> INTEGRATE
            -> PERSIST -> EXECUTE -> REUSE
```

| Class | Example evidence |
|---|---|
| ORIGIN | first located occurrence of the material |
| RELAY | artifact passed between agents (WorkClaw -> Genspark); circulation only |
| TRANSFORM | an agent materially modifies the proposition |
| ADOPT | Derek approval/adoption act |
| INTEGRATE | Derek control event ("bring this into our operation") |
| PERSIST | saved into Notion / Obsidian / repo |
| EXECUTE | VOX / DerekOS actually executes from it |
| REUSE | later re-use or re-reference |

Not every idea passes through every state. No state automatically changes
authorship. The eventual graph should answer: where did this idea first
appear, which agents changed it, what did Derek actually contribute, when
did he approve it, where was it stored, did it ever reach execution. The
actor census from RELAY_PATTERN_TEST_V0.1 is preserved as seed data.

This is how the Master Brain reconstructs the life history of an idea.
